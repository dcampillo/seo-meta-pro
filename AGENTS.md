# Agent Skills

This file configures how engineering skills interact with this repository.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (dcampillo/seo-meta-pro). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses standard triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repository with `CONTEXT.md` and `docs/adr/` at the root. See `docs/agents/domain.md`.
